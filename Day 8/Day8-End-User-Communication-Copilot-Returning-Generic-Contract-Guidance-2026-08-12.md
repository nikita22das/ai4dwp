Title: End User Communication - Copilot Returning Generic Contract Guidance  
Version: 1.0  
Date: 12/08/2026  
Status: Draft

Copilot is available and working, but in some cases it may not use the exact contract templates you expected. When that happens, answers can sound broad or generic instead of clause-specific.

This can happen if your question is too general, the template name is not mentioned, or Copilot cannot clearly match your request to the right library files at that moment.

Before opening a ticket, please try:
1. Name the exact template in your prompt.
2. Ask about one clause at a time.
3. Include document title and section name in the question.
4. Retry from the same app after reopening the document or library.

If you still need support, please share:
- The exact prompt you used
- The template name and location
- What answer you expected
- What Copilot returned
- Time of test and app used (Word, Teams, or Outlook)
- One good example and one poor example

Next step: try the prompt tips above, and if results stay generic, send those details to Support.
