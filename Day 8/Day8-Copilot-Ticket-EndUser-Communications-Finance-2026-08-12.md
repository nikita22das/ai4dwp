# End-User Communications - Copilot Tickets (Finance)

Date: 2026-08-12  
Audience: Finance users and managers

Use the messages below when responding to users. Each one explains what is happening in plain English and what to do next.

---

## Ticket 1: Cannot summarize Q3 board pack in SharePoint

Plain-English explanation:
- Copilot can only use files it is allowed to read through your current access and policy settings. Even if you can open a file manually, there can be extra permission or protection settings that limit how Copilot can use it.

Next steps:
1. Confirm the board pack is stored in the expected SharePoint location.
2. Ask your site owner to verify file and folder permissions for your account.
3. Ask the data owner to confirm whether board pack protection settings intentionally restrict Copilot use.
4. If needed, raise a DWP ticket with the file link and time of test.

---

## Ticket 2: New hire says Copilot in Outlook knows nothing about recent emails

Plain-English explanation:
- This usually happens shortly after a new account is created. Your mailbox and Copilot access may still be finishing setup and indexing.

Next steps:
1. Wait for initial setup and indexing to complete.
2. Sign out and sign back into Outlook with your work account.
3. Confirm Copilot license assignment with IT if issue continues.
4. If still not working after setup window, raise a DWP ticket.

---

## Ticket 3: HR manager gets "I don't have access to that content" for salary spreadsheet

Plain-English explanation:
- Copilot is enforcing security rules correctly. The message means your account does not currently have the right permission path to that spreadsheet content.

Next steps:
1. Open the spreadsheet directly and confirm whether access works.
2. If access fails, request permission from the document owner.
3. If access works manually but Copilot still cannot use it, ask DWP to check permissions and sensitivity settings.
4. Include the file location and screenshot of the message in your ticket.

---

## Ticket 4: Sales rep cannot find contract shared by guest link from another organization

Plain-English explanation:
- Content shared through external guest links often has limits for Copilot retrieval. Copilot works best with content in your tenant that your account can access directly.

Next steps:
1. Ask for the contract to be shared through an approved internal repository if business policy allows.
2. Confirm your access to the file without guest-link dependency.
3. Request account team support if cross-tenant sharing must remain.
4. Raise a DWP ticket if business-critical and urgent.

---

## Ticket 5: Copilot stopped for whole Finance team this morning

Plain-English explanation:
- A sudden team-wide issue is usually related to licensing, service configuration, or a temporary platform issue, not individual user error.

Next steps:
1. Do a quick test across Outlook, Teams, and Word to confirm scope.
2. Report to IT Service Desk with time issue started and sample affected users.
3. IT will verify license/service status and tenant health.
4. Watch for service update communication from DWP.

---

## Ticket 6: Copilot summarized a file manager forgot they had access to

Plain-English explanation:
- Copilot only shows content your account can access. This result usually means you still have valid permissions (often from older group memberships or inherited access).

Next steps:
1. Review access on the file and parent folder.
2. Ask owner to remove access if no longer required.
3. Request a permission review for your role if similar surprises appear.
4. Report any high-sensitivity oversharing immediately to DWP Security.

---

## Ticket 7: Analyst gets generic answers, no internal SharePoint grounding

Plain-English explanation:
- Generic responses usually mean Copilot cannot reliably use your internal content yet, often due to setup, client version, or access scope.

Next steps:
1. Confirm you are signed in to Microsoft 365 apps with your work account.
2. Update Office apps to the supported version/channel.
3. Confirm Copilot license is assigned.
4. If still generic, submit a DWP ticket with example prompts and expected source files.

---

## Ticket 8: Executive assistant cannot see shared mailbox calendar in Copilot

Plain-English explanation:
- Shared mailbox and delegated calendar access can behave differently from your own mailbox content. Copilot follows the exact delegated permissions in place.

Next steps:
1. Confirm delegated calendar/mailbox permissions are correctly assigned.
2. Ask Exchange admin to validate the delegation type and scope.
3. Retry after permission updates replicate.
4. Raise a DWP ticket if access is confirmed but Copilot still cannot use it.

---

## Standard Closing Message for Users
- Thank you for reporting this. Most Copilot issues are resolved by checking access, sharing boundaries, licensing, and client readiness first. If you still need help, send DWP the app used, prompt entered, file location (if relevant), screenshot, and time of test so we can investigate quickly.
