Title: End User Communication - Unexpected Copilot Document Access  
Version: 1.0  
Date: 12/08/2026  
Status: Draft

Copilot was able to summarize the draft settlement because your account already has some level of access to that folder or document. Copilot does not create new access to documents, and it can only work with content your account can already reach.

This does not, by itself, point to a Copilot defect. The more likely issue is that the document is available to your account in a way that was not expected, so we need to review the access carefully to confirm whether that is intentional.

Please ask the document owner or matter owner to review who should be able to see this content. If you raise this with Support, please include the document name, folder location, the time you ran the prompt, a screenshot of the Copilot response, and the exact text you entered.

Next step: please send those details to Support so the access can be reviewed.
