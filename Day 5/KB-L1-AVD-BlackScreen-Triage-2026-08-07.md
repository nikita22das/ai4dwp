# Service Desk Guide - Black Screen After Sign-In (Phone Support)

## Version Header

- v 1.0
- Date: 07/08/2026
- status: Draft

## Audience

First-line service desk staff.

## Purpose

Give staff a quick, consistent way to help users who see a black screen after sign-in or who keep getting sent back to the sign-in page.

## What to say to the user

Use calm language:
- I can help you with this now.
- Your files and saved work are safe.
- Please try one safe sign-in attempt with me, then I will pass this to the next support team if it happens again.

## Safe Steps You Can Guide

1. Ask the user to wait for 2 minutes on the current screen.
2. Ask the user to sign out.
3. Ask the user to sign in one time only.
4. Ask if the desktop loads normally.
5. If not fixed, stop extra sign-in attempts and pass the case to the next support team.

## What Good Looks Like

- User reaches a normal desktop.
- No black screen appears after the single sign-in attempt.
- User can open normal work apps.

## Pass To The Next Support Team Immediately If Any Of These Happen

- Black screen appears again after one guided sign-in attempt.
- User is signed out repeatedly.
- Multiple users from the same business area report the same issue within 30 minutes.
- User cannot access important work after the guided sign-in attempt.

## Notes For First-Line Staff

- Do not ask the user to perform technical fix steps.
- Do not ask the user to run actions that need special IT permissions.
- Do not repeat sign-in attempts more than once.
- If the user reports urgent work impact, mark the request high priority and pass it to the next support team at once.
